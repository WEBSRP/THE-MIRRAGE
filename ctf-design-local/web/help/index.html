Help & Documentation

User guides, forum usage guidelines, and technical troubleshooting FAQs.

Frequently Asked Questions

  • How do I join the MIRRAGE researcher network?
    Membership is open to defensive researchers and system engineers. You may read public forums and advisories immediately or create a research contributor handle to submit reports.
  • Where can I post security advisories or ask technical questions?
    All community topics, incident discussions, and vulnerability disclosures are hosted on the MIRRAGE Community Forum.
  • Why was my thread delayed in appearing on the board?
    New posts are held in an automated validation queue where content syntax and references are processed before public listing.

Forum Usage & Post Preprocessing

When drafting a new topic on Forum Submit, authors can preview and validate their post formatting prior to publishing.

  • Supported Syntax: Plaintext, standard Markdown, and technical preformatted blocks.
  • Validation Engine (Beta): The forum submission endpoint features a built-in preprocessor utility. In addition to default formatting, beta testers and platform engineers can invoke custom formatting utilities via the preprocessor parameter to verify output rendering.
  • Output Inspection: Running the preprocessor captures standard stream output and displays the diagnostic results in the preview console.

Account & Access Troubleshooting

  • SSH Administrative Access: Terminal access for verified infrastructure operators is strictly managed via key-based authentication on the maintenance port (port 2222 externally). Standard contributors do not require terminal credentials.
  • Session Resets: If your browser loses session context during submission preview, clear your cookies or test directly using standard HTTP POST requests.
  • Platform Node Status: All core services including the web server reverse proxy and forum submission backend run under isolated system accounts.
